三、制冷系统工作原理 制冷系统基于“制冷剂相变（汽态-液态）”实现热量转移，核心流程分为压缩、冷凝、

节流、蒸发四个阶段，如图 6-10 所示。

![](<《新能源汽车电气技术》打印(3)_images/imageFile2.png>)

图 6-10 制冷系统工作循环

- 1）压缩阶段：高压电动压缩机将蒸发器回流的低温低压气态制冷剂压缩为高温高压气

态（温度约 80~100℃，压力约 1.5~2.5MPa），并输送至冷凝器。

- 2）冷凝阶段：高温高压液态制冷剂流经冷凝器，在风冷（冷凝器风扇）作用下，热量

被散发到大气中，制冷剂温度降至 50-60℃，变为中温高压液态。

- 3）节流阶段：中温高压液态制冷剂经过储液干燥器过滤干燥后，进入电子膨胀阀。电

子膨胀阀通过阀芯节流，将制冷剂压力骤降至 0.2-0.5MPa，温度降至 5-10℃，变为低温低压 液态；

- 4）蒸发阶段：低温低压液态制冷剂进入蒸发器，与车内高温空气进行热交换——制冷


剂吸收热量蒸发为气态（温度降至 0~5℃），车内空气温度降低，经鼓风机吹入车内实现制 冷；气态制冷剂再回流至压缩机，完成循环。
