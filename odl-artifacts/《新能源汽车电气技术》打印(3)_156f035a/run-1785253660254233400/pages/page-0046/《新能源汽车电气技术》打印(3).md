新能源汽车的进入及防盗系统主要由智能钥匙模块（Key-less Ecu）、遥控钥匙、车外探

测天线、车身控制模块（BCM）、微动开关等组成。 1.智能钥匙模块（Key-less Ecu） 智能钥匙模块（Key-less Ecu）是无钥匙进入的主控单元，也是钥匙授权识别代码的解码 器，模块上连接有内外部探测天线、车门微动开关等，智能钥匙模块的主要作用包括：接收 车门微动开关的信号变化，通过低频发射驱动芯片驱动天线产生 125KHz 的低频信号（包括 钥匙唤醒信息、ID 码询问信息等），通过内部的高频接收模块接收钥匙发出的高频信号进 行车门防盗验证，同时通过起动子网与车身控制模块进行通信、信息交互等。比亚迪秦 EV 的智能钥匙模块安装在行李舱左上部，如图 2-1 所示。
