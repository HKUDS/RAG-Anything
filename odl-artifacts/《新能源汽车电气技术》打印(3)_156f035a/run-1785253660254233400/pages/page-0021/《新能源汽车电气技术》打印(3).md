进行插接器的连接操作时，需先将部件的导向槽对齐重合，使插头与插孔精准对位后适 度施力插入，以此实现稳固的连接效果。

为避免汽车行驶过程中插接器松脱，所有该部件均配备闭锁机构。拆卸插接器时，需先 按压闭锁部件，再进行分离操作。若未按压闭锁，严禁强行拉扯导线，以免损坏闭锁机构或 导线本身，如图 1-10 所示。

3.继电器的检修 诊断继电器的核心方法，是对其电路进行测试。开展这一测试的首要任务，是厘清继电
