# 项目五 新能源汽车车载网络系统检修

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

随着全球能源结构调整与碳中和目标的推进，新能源汽车已成为汽车产业转型的核心 方向。以纯电动汽车（BEV）、插电式混合动力汽车（PHEV）和燃料电池汽车（FCEV）为代 表的新能源汽车，凭借其零排放、高能效和智能化特性，正在加速替代传统燃油车。然而， 这一技术迭代的背后是车载电子电气架构的颠覆性变革——由分布式控制向集中式域控制 演进，车载网络系统的复杂度呈现指数级增长。

随着新能源汽车上的功能越来越多，车上的控制单元也越来越多，这些控制但愿之间需 要时刻进行数据传输和交互，一方面需要接收来自其他控制单元的指令，另一方面，它们需 要将指令传递给执行器以执行相关的操作。所以通信和交互的准确性、可靠性和高效性需要 依靠总线技术来保证。目前，汽车的网络连接根据传递的信息量的速度、网络特性，可以分 为 CAN、LIN、MOST 等不同的网络系统，见表 5-1。

表 5-1 车载网络类型

|等级|功能|速率（bit/s）|应用功能|代表网络|
|---|---|---|---|---|
|A|面向传感器或执行器管理的低 速网络|＜20K|后视镜、电动车窗和灯光 照明设备调节等|LIN|
|B|面向独立控制单元的信息共享 中的中速网络|100K-125K|车身电子的舒适性模块 和显示仪表等设备|低速 CAN|
|C|面向闭环控制的多路传输高速 网络|500K-2M|动力、底盘系统等|高速 CAN|
|D|面向多媒体设备、高速数据传 递的高性能网络|＞2M|多媒体设备等|MOST、蓝牙、 FlexRay|


新能源汽车的车载网络系统不仅承载着车辆的控制、通信和信息娱乐功能，还与车辆的 安全性、可靠性和用户体验密切相关。因此，掌握新能源汽车车载网络系统的检修技术，对 于保障车辆的正常运行、提升维修效率和质量具有重要意义。
