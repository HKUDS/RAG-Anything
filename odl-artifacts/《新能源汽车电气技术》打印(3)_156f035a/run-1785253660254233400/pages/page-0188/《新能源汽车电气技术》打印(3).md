- 3）每个控制单元的发射器都将 TX 线和 RX 线的状态一位一位地进行比较(它们可以不

一致)。

- 4）数据传输总线的调整规则：用标识符中位于前部的“0”的个数代表信息的重要程度，


“0”的位数越多越优先，从而保证按重要程度的顺序来发送信息。越早出现“1”的控制单 元，越早退出发送状态而转为接收状态。基于安全考虑，涉及安全系统的数据优先发送。

例如，见表 5-2，ABS 控制单元、电机控制单元、车身控制单元都要发送数据，那通过 比较各自状态域的 11 位标识符来确定信息的优先级，ABS 控制单元优先级最高，其次是电 机控制单元，最低的是车身控制单元。

表 5-2 CAN 总线数据优先级比较

|优先权|控制器|状态区的标识符|
|---|---|---|
|1|ABS 控制单元|001 1010 0000|
|2|电机控制单元|010 1000 0000|
|3|车身控制单元|100 0100 0000|
