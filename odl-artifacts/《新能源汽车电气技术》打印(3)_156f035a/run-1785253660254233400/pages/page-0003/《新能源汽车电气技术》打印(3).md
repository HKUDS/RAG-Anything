# 前言

当前我国正深入贯彻习近平新时代中国特色社会主义思想，全面落实党的二十大与党的 二十届三中全会精神，以制造强国、交通强国、教育强国战略为引领，大力推进新能源汽车 产业高质量发展与现代职业教育体系改革。国家密集出台《汽车行业稳增长工作方案（2025 —2026 年）》《关于推动现代职业教育高质量发展的意见》等政策，明确加快构建职普融 通、产教融合的职业教育体系，聚焦新能源、智能网联等战略性新兴产业，培养大批高素质 技术技能人才、能工巧匠、大国工匠，为中国式现代化建设提供坚实支撑[1][2][3]。

新能源汽车作为汽车产业转型升级的核心方向，呈现电动化、智能化、网联化、集成化 深度融合趋势，电气系统已成为支撑整车安全运行、智能交互、高效驱动的“神经网络”。 产业快速扩张与技术迭代，使得新能源汽车电气技术成为职业院校汽车类专业核心课程，而 市场亟须一套对接产业标准、贴合岗位需求、理实一体化的精品教材，破解教学内容滞后、 实训与实战脱节、技能培养与企业需求错位等痛点。

为响应国家政策导向、服务院校人才培养、支撑行业技术升级，我们组织长期深耕新能 源汽车教学一线、企业技术研发与售后维修的专家团队，编写本教材。编写全程坚持立德树 人根本任务，立足职业教育类型定位，遵循岗位导向、能力本位、理实交融思路：以比亚迪 秦 EV 等主流车型为实战载体，从电气系统认知、电路图识读、核心元件检修，到进入及起 动系统、仪表灯光、辅助电气、车载网络系统检修，构建“基础认知—识读技能—元件检修 —系统排故—综合实战”的递进式知识技能体系；每个项目均设置学习目标、任务情景、知 识准备、任务实施、任务评价、课后习题，实现“学、练、测、评”闭环，突出做中学、学 中做的职教特色。本教材具有以下鲜明特色：

- 1.政策引领，对标产业。紧扣国家新能源汽车产业政策与职业教育改革要求，融入最新

行业标准、技术规范与故障诊断流程，对接企业真实岗位能力需求。

- 2.车型典型，实战落地。以市场保有量大、技术代表性强的比亚迪秦 EV 为核心实训车

型，电路图、元件参数、检修流程均源自原厂维修手册，可直接用于实车操作。

- 3.理实一体，分层递进。理论讲解通俗易懂，实操步骤规范详尽，从电气元件识别、电

路图识读等基础技能，逐步过渡到整车系统故障排查，适配中职、高职不同层次教学。

- 4.全为本，规范先行。全程贯穿高压安全、操作规范、检修流程，强化职业素养与安全

意识，贴合企业“安全第一、规范作业”要求。

- 5.评价闭环，以评促学。设置小组评价、教师评价、工单填写、7S 管理等多元评价体
