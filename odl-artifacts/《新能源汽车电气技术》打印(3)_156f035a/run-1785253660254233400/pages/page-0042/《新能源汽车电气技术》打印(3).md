# 项目二 新能源汽车进入及起动系统检修

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

随着新能源汽车的市场占比不断增加，新能源汽车已成为汽车产业转型的核心方向，技 术不断更新迭代，其工作原理与传统燃油车截然不同，尤其进入及起动系统也发生了的改变。 新能源汽车的进入及起动系统是掌握高压电安全与整车能源管理逻辑的关键环节，新能源汽 车的起动，绝非仅是点亮仪表板。由于其核心是动力蓄电池系统的上电流程，因此保证上电 的安全性尤为重要。因此在上电的过程中不仅仅是动力蓄电池的对外输出，还要进行一系列 的安全检查，例如“高压互锁检测”、“绝缘监测”等[9]。

为实现其安全可靠上电，目前新能源汽车进入及起动通过低压上电来控制高压上电，因 此其涉及的环节和模块多，见表 2-1。

表 2-1 新能源汽车进入及起动系统相关模块

|模块|应用功能|所属局域网|
|---|---|---|
|智能钥匙模块|寻找合法钥匙并解码|起动子网|
|车身控制模块|与智能钥匙模块协同解锁车辆，控 制低压上电|舒适网|
|整车控制单元|与各模块通信，进行决策指令|动力网|
|动力蓄电池管理系统|监测蓄电池状态，互锁检测，绝缘 检测，并控制接触器吸合|动力网|
|驱动电机管理系统|监测电机状态|动力网|
|充配电总成|监测充电状态|动力网|
