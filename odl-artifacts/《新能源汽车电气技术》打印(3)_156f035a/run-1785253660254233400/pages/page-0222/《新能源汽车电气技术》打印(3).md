# 任务一 制冷系统检测与维修

##  学习目标

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

知识目标

- 1.理解新能源汽车制冷系统的概念、特点及与传统燃油车制冷系统的差异；
- 2.掌握制冷系统的结构组成及工作原理；
- 3.掌握制冷系统常见故障的诊断逻辑与排除方法；
- 4.熟悉制冷系统制冷剂的特性及规范操作要求。


![](<《新能源汽车电气技术》打印(3)_images/imageFile2.png>)

## 能力目标

- 1.能够查询原车电路图，绘制制冷系统的核心部件连接框图；
- 2.能够规范使用制冷剂回收机，完成压力测量、抽真空、制冷剂回收与加注；
- 3.能够通过数据流（如压缩机转速、蒸发箱温度、制冷剂压力）分析制冷系统工况，定

位故障部件；

- 4.能够独立完成制冷系统检测（如肥皂水检漏）及密封修复。


![](<《新能源汽车电气技术》打印(3)_images/imageFile3.png>)

## 素养目标

- 1.养成严格遵守制冷剂操作规范的习惯，树立环保意识；
- 2.培养逻辑分析能力——通过“现象→数据→故障点”的推导，高效排查复杂故障；
- 3.提升团队协作能力，在实训中明确分工，确保操作安全；
- 4.形成“先诊断后维修”的思维，避免盲目拆装导致部件二次损坏。
