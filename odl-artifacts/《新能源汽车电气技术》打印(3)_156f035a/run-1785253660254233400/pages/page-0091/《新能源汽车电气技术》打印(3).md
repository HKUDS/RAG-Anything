#  知识拓展：悬浮式全液晶仪表

随着科技与审美趣味的发展，新能源汽车仪表在结构和显示技术上也经历了变迁，许多 新能源汽车抛弃了传统的内嵌式仪表结构设计，而采用了悬浮式的仪表；显示技术的变迁主 要体现在半液晶仪表板向全液晶仪表板的转变倾向。

# 一、仪表板显示技术

汽车仪表作为车辆关键信息的显示窗口，其显示技术具有明显的时代特点。最早的汽 车仪表板采用纯机械式显示设计，通过机械传递方式将车速、转速、油量、水温等信息引入 仪表板，用指针来进行信息的显示，如图 3-9 所示。这种设计就像机械手表，信息存在误差 且交互方式复杂，如今基本已成为被缅怀的经典。
