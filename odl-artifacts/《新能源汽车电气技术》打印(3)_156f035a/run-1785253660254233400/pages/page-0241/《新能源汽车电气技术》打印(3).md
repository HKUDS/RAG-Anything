 任务情景

某维修厂接到一辆 2021 款北汽 EU5 纯电动汽车，车主反馈：冬季开启暖风后，车内升 温缓慢，出风口温度最高仅 15℃（设定温度 25℃），且前风窗玻璃除霜效果差（半小时仍 有雾气）。维修技师小王需先分析该车暖风系统的类型（PTC 加热），结合诊断仪读取的 PTC 工作参数，排查是否存在 PTC 功率不足、暖风芯体堵塞或鼓风机故障，最终完成维修。

你需要协助小王梳理维修流程，确保快速解决问题。

|对比维度|PTC 加热器系统|热泵系统|
