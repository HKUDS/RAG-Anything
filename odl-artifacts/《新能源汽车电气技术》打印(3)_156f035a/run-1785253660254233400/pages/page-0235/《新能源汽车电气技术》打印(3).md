# 三、实训安全要求及注意事项

- 1）高压安全：新能源汽车制冷系统的压缩机为高压部件，操作前需确认车辆下高压电

（关闭点火开关，断开辅助蓄电池负极，等待 5min 以上），佩戴高压绝缘手套，禁止在未 断电时拆卸压缩机高压插头。

- 2）制冷剂安全：制冷剂为低温易挥发气体，泄漏时可能导致冻伤，操作时需佩戴护目

镜、防毒面具；禁止将制冷剂直接排放到大气中（需用回收机回收）。

- 3）设备安全：回收机需接地（避免漏电）；测量管路使用前需检查软管是否老化（避

免破裂泄漏）。

- 4）操作规范：拆卸制冷剂管路前需先回收制冷剂；抽真空后需保压，确认无漏点后再


加注制冷剂；禁止用明火加热制冷剂管路。

# 四、实施过程

- （1）故障现象确认 起动比亚迪元 PLUS，开启空调最大制冷模式，5min 后出风口温

度为 18℃（标准≤10℃），诊断仪读取数据流显示：低压侧压力 0.05MPa（标准 0.2~0.5MPa）， 压缩机转速 2000r/min（正常），判断为制冷剂不足（可能泄漏）。

- （2）泄漏检测 通过肥皂水法检测发现冷凝器与储液干燥器的接口处有小气泡，表示

有泄漏（密封垫老化）。

- （3）故障修复


- 1）回收制冷剂：连接回收机，抽取系统内剩余制冷剂（回收量约 200g，标准需 600g，

确认泄漏导致制冷剂流失）。

- 2）更换密封垫：拆卸冷凝器与储液干燥器的连接螺栓，更换新的丁腈橡胶 O 形圈（规

格φ10mm×2mm）。

- 3）抽真空：连接制冷剂回收加注机，运行 40min，真空度稳定在 3Pa（符合要求），

保压 10min 无回升；

- 4）加注制冷剂：按厂家规定加注 R134a 600g。
