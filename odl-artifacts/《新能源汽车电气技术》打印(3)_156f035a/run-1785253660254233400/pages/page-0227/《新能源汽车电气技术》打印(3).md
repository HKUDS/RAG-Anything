电动压缩机主要包括一对螺旋线缠绕的固定蜗形管和可变蜗形管、无刷电动机、油挡板 和电动机轴，如图 6-2 所示。压缩机工作受空调控制单元（ACU）控制，通过 PWM 信号调 节转速（范围通常为 1000~8000r/min）。

（2）电动压缩机的工作过程

- 1）进气行程：在固定蜗形管和可变蜗形管间产生的压缩室的容量随着可变蜗形管的旋

转而增大，这时，气态制冷剂从进风口吸入。

- 2）压缩行程：吸入步骤完成后，随着可变蜗形管继续转动，压缩室的容积逐渐减小，

吸入的气态制冷剂逐渐压缩并被排到固定蜗形管的中心，当可变蜗形管旋转约两周后，制冷 剂的压缩完成。

- 3）排放过程：气态制冷剂压缩完成而压力较高时，通过按压排放阀，气态制冷剂通过


固定蜗形管中心排放口排出。 电动压缩机工作的三个过程如图 6-3 所示。
