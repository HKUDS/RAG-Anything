比亚迪秦 EV 微动开关通常位于车门把手钥匙孔旁边以及行李舱中间开启位置附近，是 一个拇指头大小的正方形按钮。其结构主要由外壳、驱动机构、触点系统和弹簧等部分组成， 微动开关通过线束与智能钥匙模块相连，当被按压后会给 Key-less Ecu 电压拉低信号传递解 闭锁需求信息。微动开关根据车辆的配置不同安装数量也不一样，低配车型只配备了驾驶人 侧门把手，高配车型会增加副驾、后排和行李舱微动开关。
