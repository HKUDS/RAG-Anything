亚迪秦 PLUS EV 的组合开关，其位置在转向盘左下侧位置，调节功能涵盖前照灯旋钮、雾灯 旋钮、变光切换和转向切换四部分。

- （1）前照灯旋钮 分为关闭、自动灯光（AUTO）、位置灯（示宽灯或示廓灯）、近光

灯（前照灯）四个挡位，其中旋钮旋至 AUTO 挡时，系统会通过光线传感器感知外界环境明 暗度，当外界光线暗于设置值时，会自动打开近光灯，当外界光线强度高于设置值时，会自 动关闭近光灯。

- （2）雾灯旋钮 负责打开或关闭雾灯，操作有效的前提是近光灯打开状态。
- （3）变光切换 在近光灯开启的前提下，将开关向后拨动，打开远光灯，向前拨动，

打开超车灯。

- （4）转向切换 将开关向下拨动，打开左转向灯，向上拨动，打开右转向灯。
