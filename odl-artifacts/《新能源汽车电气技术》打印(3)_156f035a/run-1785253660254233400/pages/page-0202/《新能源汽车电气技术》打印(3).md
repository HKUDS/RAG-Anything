- 1.CAN 总线为事件触发的实时通信网络，其总线仲裁方式采用基于优先级的载波侦听多

路访问冲突检测法。（ ）

- 2.CAN 总线可以连接无穷多个节点，不受线路和传输速率的限制。（ ）
- 3.CAN 总线上的电控单元与非网络电控单元一样，不需要对外进行数据交换（ ）
- 4.因为大部分执行器是模拟执行器，所以首先要将单片机输出的数字信号经数/模转换

电路（D-A 转换）转换为模拟信号。（ ）

- 5.以光为媒介传送信号，对输入和输出电路进行电气隔离，因而能有效地抑制系统噪声，
