#  知识拓展：CAN FD

CAN FD（Controller Area Network with Flexible Data-rate）是一种改进的 CAN 协 议，旨在克服传统 CAN 协议在数据传输速率和数据帧大小上的限制，由博世在 2012 年推出， CAN FD 标准化为 ISO11898-1:2015。

一、CAN FD 技术规格 传输速率：CAN FD 的平均比特率可以达到 2-4 Mbit/s，最高可达 8 Mbit/s。 数据字段：每个 CAN 帧的数据字节数从最多 8 个扩展到 64 个，如图 5-13 所示。 帧格式：通过修改 CAN 帧格式，比特率可以在 CAN 帧内切换到更快的值，并通过新的数

据长度编码来实现。

错误检测：CAN FD 协议具有更强的错误检测和纠正机制，确保数据传输的高可靠性和 完整性。
