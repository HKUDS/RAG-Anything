 知识准备 一、新能源汽车起动系统的认识 传统汽车起动系统是通过将蓄电池的电能转化为机械能来驱动发动机运转的关键装置，

主要由蓄电池、点火开关、起动继电器和起动机等部件组成 。其核心功能是克服发动机静 止状态下的阻力，使曲轴转动并完成气缸内混合气的首次燃烧。在新能源汽车（纯电动、插 电式混合动力）中，“高压上电系统”就是替代传统燃油车起动系统的核心系统，其核心功 能是在车辆起动时，通过精准控制将动力蓄电池的高压电安全、有序地输送至电动机、空调 压缩机、DC/DC 转换器等高压用电部件，同时实现全程高压安全监控。新能源汽车的“起 动”本质是安全地建立高压供电通路，使车辆进入可行驶的“就绪”状态，这个过程称为高压 上电。

新能源汽车的起动系统可以实现以下功能。

- 1.动力起动基础 只有完成高压上电，电机控制器（MCU）才能获得电能，驱动电机运转，带动车辆行驶。
- 2.高压安全管控 全程监测高压回路的绝缘性能、高压线束连接状态、电流电压异常等，一旦出现故障（如


绝缘破损、线束松动），立即切断高压回路，避免触电或部件损坏。 3.能量精准分配 通过高压配电盒将动力蓄电池的电能分配至不同高压负载（如电机、空调、充电模块），

满足车辆行驶、舒适功能的差异化用电需求。
