灯光不够亮主要有供电电压不足，灯体自身故障、线路接触不良或损坏等原因。此外， 灯罩发黄、蒙尘或密封不亮等问题也会影响灯光亮度。灯光亮度对行车安全有着较大影响， 应注意日常检查和维护，保证其正常工作。
