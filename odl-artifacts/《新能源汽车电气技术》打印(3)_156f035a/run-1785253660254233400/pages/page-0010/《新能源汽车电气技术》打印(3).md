- 1）熔丝：用于保护低压局部电路或高压支路电路，限额电流标注在外壳上，核心元件

为锌、锡铅、铜等合金熔丝片，按外形分为插片式、熔管式等，过载时熔丝片熔断，切断故 障回路。

- 2）手动维修开关（MSD）：新能源汽车高压系统专属核心保护元件，安装在高压主回路

中，维修高压部件（如动力蓄电池、驱动电机）前，必须断开 MSD，切断高压回路，避免触 电风险，是高压安全的关键保障。

- 3）熔断器：适配高压大电流场景，额定电流大于普通熔丝，用于高压主电路（如动力

蓄电池输出回路、驱动电机供电回路）保护，过载或短路时快速熔断。

- 4）电路断电器：分为自动复位和手动复位两类，适配充电桩、高压配电盒等场景，检


测到漏电、超负荷时自动断开电路，故障排除后可复位复用，避免频繁更换元件。

易熔线：截面积小于被保护电线的铜芯或合金导线，用于保护高压总电路或大电流支路 （如动力蓄电池至高压配电箱回路），外部包裹聚乙烯护套，长度 50-200mm，通过插接件 接入电路，过载时优先熔断，且不得绑扎于线束内或被其他物品包裹，确保熔断时能快速切 断电路。
