# 内容简介

本书遵循校企合作、产教融合的原则，由高职院校“双师型”教师，行业、企业专家共 同编写。本书围绕 “职业能力为核心”的编写理念，内容包括新能源汽车电气系统认知、 新能源汽车进入及起动系统检修、新能源汽车仪表及灯光系统检修、新能源汽车辅助电气系 统检修、新能源汽车车载网络系统检修、新能源汽车空调系统检修 6 个项目。本书内容由浅 到深、循序渐进，突出工学结合，严格按照工作岗位要求设计和划分工作任务。本书采取理 论和实践相结合的方式编写，大部分任务都包括学习目标、任务情景、知识准备、任务实施 以及任务评价，任务实施主要以元件检测、系统检测以及电路故障诊断为主题，引领学生掌 握“记录故障现象”“故障分析与诊断”“电路排故与修复”等核心维修思路。

本书采用了“互联网 +”形式，以二维码的形式嵌入视频、动画、虚拟仿真等数字资源， 以满足读者线上和线下学习的需求。

本书可作为职业院校新能源汽车技术、汽车检测与维修技术、汽车电子技术及相关专业 的教学用书，也可作为新能源汽车维修企业内部培训用书，还可作为新能源汽车维修技术人 员的参考用书。
