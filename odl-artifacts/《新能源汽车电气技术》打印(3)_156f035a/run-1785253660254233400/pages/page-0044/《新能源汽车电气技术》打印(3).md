# 任务一 新能源汽车进入及防盗系统检测与维修

##  学习目标

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

知识目标

- 1.理解新能源汽车进入及防盗系统的概念、特点及结构组成；
- 2.掌握新能源汽车进入及防盗系统工作原理；
- 3.掌握新能源汽车进入及防盗系统常见故障诊断技巧。


![](<《新能源汽车电气技术》打印(3)_images/imageFile2.png>)

能力目标

- 1.能够查询原车电路图，并且能够画出对应车辆新能源汽车进入及防盗系统框架图；
- 2.能够规范进行新能源汽车进入及防盗系统相关模块信号的测量；
- 3.能够诊断与排除新能源汽车进入及防盗系统常见故障。


![](<《新能源汽车电气技术》打印(3)_images/imageFile3.png>)

素养目标

- 1.能够通过实践项目养成灵活思维、团队协作意识；
- 2.养成反思与总结的习惯，持续改进不足，精益求精；
- 3.尝试多元化思考解决问题的方法，形成创新意识；
- 4.积极主动与小组成员交流、讨论学习成果，取长补短，完成自我提升。
