图 6-1 新能源汽车空调制冷系统的组成 1.电动压缩机

电动压缩机是新能源汽车空调制冷系统的心脏，其作用是维持制冷剂在制冷系统中的循 环，吸入来自蒸发器的低温、低压气态制冷剂，压缩转变为高温高压的气态制冷剂送往冷凝 器。目前纯电动汽车空调上的电动压缩机是高压核心动力部件，由动力蓄电池（如 300~400V） 供电，常见类型为涡旋式压缩机，具有体积小、噪声低、效率高的特点（如比亚迪的 12V 直流压缩机、特斯拉的 400V 高压压缩机）。
