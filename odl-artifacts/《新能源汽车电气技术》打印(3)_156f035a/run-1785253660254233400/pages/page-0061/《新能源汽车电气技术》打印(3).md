# 任务二 新能源汽车起动系统检测与维修

##  学习目标

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

知识目标

- 1.理解新能源汽车起动系统的概念、特点及结构组成；
- 2.掌握新能源汽车起动系统工作原理；
- 3.掌握新能源汽车起动系统常见故障诊断技巧。

- 1.能够查询原车电路图，并且能够画出对应车辆新能源汽车起动系统框架图；
- 2.能够规范进行新能源汽车起动系统相关模块信号的测量；
- 3.能够诊断与排除新能源汽车起动系统常见故障。


![](<《新能源汽车电气技术》打印(3)_images/imageFile3.png>)

素养目标

- 1.能够通过实践项目培养工程思维；
- 2.通过检测数据培养学生的细心耐心；
- 3.通过电路分析，培养学生的逻辑思维，举一反三；
- 4.积极主动与小组成员交流、讨论学习成果，取长补短，完成自我提升。
