 知识准备 一、比亚迪电路图中线束、插接件编码 1.线束编码 注意事项：本章节涉及的线束零部件详细编号、插接器称谓、配电盒接口名称，以及电

路维修图纸中熔丝、继电器的命名规则等，均依据比亚迪相关标准予以规范确定。

线束是汽车电路的连接载体，比亚迪车系电路图通过特定编码明确线束的位置、类型及 连接关系，核心规则如下：

- （1）线色与线径标识

- 1）线色编码：采用单个字母表示，例如“R”代表红色、“G”代表绿色、“B”代表蓝

色，具体线色表示见表 1-6。

- 2）双色线标识：采用“主色/辅色”格式，如“R/G”表示红色为主色、绿色为辅助色。
- 3）线径标识：数字表示导线横截面积（单位：mm²），如“0.5”表示线径为 0.5mm²。
- 4）附加标识：“ALL”表示该线束为全车通用型。 表 1-6 线色标准

- （2）线束位置编码 编码首字母代表线束装配位置，第二位字符代表线束类型或连接 对象：“2”表示仪表板主配电盒、“J”表示线束间对接插接件、空位表示一般类插接件； 后续数字或字母为排序代码，用于区分同一位置的不同线束或插接件。


典型编码示例： 编码“C2X”：“C”（仪表板线束）+“2”（仪表板主配电盒）+“X”（配电盒 X 口插

接件），表示仪表板主配电盒 X 口的插接件。
