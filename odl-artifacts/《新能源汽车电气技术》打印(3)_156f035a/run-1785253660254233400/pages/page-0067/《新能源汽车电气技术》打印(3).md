一般在电动汽车的蓄电池包内部均有蓄电池信息采集模块，负责采集来自蓄电池单元的 物理信号（如电压、电流、温度等），将采集的信息通过蓄电池子网告知 BMS，进行蓄电 池状态的判断。在高压上电时，蓄电池要满足其上电的电量，电压和温度要求。

（3）预充 高压上电条件满足后，BMS 会闭合负极接触器和预充接触器进入预充阶段。

预充的核心作用只有一个：限制冲击电流，保护高压元器件。高压系统的母线电压通常高达 300V-800V。而电机控制器（逆变器）内部有非常大的滤波电容，在初始状态下，这些电容 相当于短路。如果没有预充电路，在主接触器（继电器）闭合的瞬间，电容会产生一个极大 的冲击电流（理论上可达数千安培），这个巨大的电流会在接触器触点闭合的瞬间产生强烈 的电弧，迅速烧蚀和熔焊接触器的触点，导致接触器损坏或失效。巨大的瞬间电流也会对蓄 电池本身、电容以及整个高压线路造成冲击，可能引发故障或缩短元器件使用寿命。

预充的原理基于 RC 电路的充电特性，通过在供电回路中增加预充电阻，降低充电电流。

预充时，电流流经预充电阻，限制了最大充电电流。随着电容两端电压逐渐升高，它与蓄电 池电压之间的压差越来越小，流过预充电阻的电流也越来越小。当电容电压非常接近蓄电池 电压时，就可以安全地闭合主接触器了。图 2-23 所示为比亚迪秦 EV 三个接触器的工作原理 图，主负接触器、主正接触器、预充接触器在蓄电池包的内部，其线圈由 BMS 通过低压电 路控制。当 BMS 确认高压上电条件满足后，通过 BK45(A)/16 和 BK45(A)/29 控制主负接触器 的线圈通电，通过 BK45(A)/7 和 BK45(A)/21 控制预充接触器的线圈通电，吸引触点闭合，通 过触点线路中增加预充电阻降低充电电流，完成预充。接触器相比普通继电器功率大，由 IG3 继电器控制的双路电为其正极供电电源。
