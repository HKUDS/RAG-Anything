四、制冷系统关键参数与测量 制冷剂压力通过制冷剂回收加注机的高低压表测量系统高压侧（冷凝器出口）与低压侧

（蒸发器入口）压力，正常工况下（环境温度 30℃，空调最大制冷）参数如下：

- 1）高压侧压力：1.5-2.2MPa（R134a）、1.4-2.0MPa（R1234yf）；
- 2）低压侧压力：0.2-0.5MPa（R134a）、0.15-0.45MPa（R1234yf）。 若高压过高（＞2.5MPa），可能是冷凝器脏堵、风扇不转；若低压过低（＜0.1MPa），


可能是制冷剂泄漏、膨胀阀堵塞。

出风口温度空调最大制冷模式下，出风口温度应≤10℃（环境温度 30℃）。若温度＞ 15℃，需检查压缩机转速、电子膨胀阀开度、蒸发器是否结霜。

压缩机工作参数通过诊断仪读取压缩机相关数据流：

- 1）压缩机电压：高压压缩机通常为 300~400V（与蓄电池电压匹配），低压压缩机为 12V。
- 2）压缩机转速：正常范围 1000-6000rpm（根据制冷需求调整）。
