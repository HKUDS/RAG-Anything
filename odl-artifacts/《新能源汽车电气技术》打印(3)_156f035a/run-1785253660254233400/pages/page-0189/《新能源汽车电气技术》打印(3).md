由于数据总线在信号传输过程中会遇到不同类型的干扰，而采用双绞线并利用差动信号 放大器进行信号处理，就解决了 CAN 总线系统的信号干扰问题。如图 5-12 所示，信号通过 两根导线（CAN-High 和 CAN-Low）以互补的形式传输，接收端只关心两根线的电压差， 而不是绝对电压值。这样一来，外界的干扰信号（比如电磁噪声）会同时作用在两根线 上，形成所谓的“共模信号”。而接收端的差分电路会直接把这些共模信号抵消掉，只 提取有用的“差模信号”。这种设计让干扰信号无处遁形，信号传输的可靠性自然大大 提升。
