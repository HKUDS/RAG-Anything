CAN 总线使用差分信号，通常采用双绞线（如图 5-3 所示）作为载体，以减少干扰。双 绞线的使用可以提高信号的稳定性和抗干扰能力。在新能源汽车中，根据不同的应用需求， CAN 总线可以分为高速 CAN 和低速 CAN。高速 CAN 通常用于传输实时性要求较高的数据，如 动力系统的控制信息，其传输速率可以达到 1Mbps；而低速 CAN 则用于传输对实时性要求不 高的数据，如车身控制信息，其传输速率一般在 125kbps 左右。
