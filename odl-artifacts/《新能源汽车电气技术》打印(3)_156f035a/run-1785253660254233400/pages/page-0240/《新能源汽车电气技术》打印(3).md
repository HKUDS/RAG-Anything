# 任务二 暖风加热系统检测与维修

##  学习目标

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

知识目标

- 1.理解新能源汽车暖风加热系统的核心作用（冬季制热、除霜除雾）及与传统燃油车的

差异；

- 2.掌握暖风加热系统的主要类型（PTC 加热器、热泵系统）及工作原理；
- 3.熟悉暖风加热系统的硬件结构（如 PTC 加热器、暖风芯体、鼓风机、控制单元）；
- 4.掌握暖风加热系统常见故障（如制热不足、PTC 不工作、除霜效果差）的诊断与排除


方法。

![](<《新能源汽车电气技术》打印(3)_images/imageFile2.png>)

能力目标

- 1.能够查询电路图，绘制暖风加热系统的控制逻辑框图（如 PTC 与高压配电盒的连接）；
- 2.能够使用万用表、诊断仪检测 PTC 加热器的供电、接地及通信信号；
- 3.能够通过数据流（如 PTC 工作电流、暖风芯体温度）分析系统工况，定位故障部件；
- 4.能够独立完成 PTC 加热器的拆装、暖风芯体的清洁及鼓风机的故障排查。


![](<《新能源汽车电气技术》打印(3)_images/imageFile3.png>)

素养目标

- 1.养成高压系统操作的安全意识；
- 2.培养“能耗与制热效果平衡”的思维——理解 PTC 制热对续航的影响，避免盲目维修

导致能耗增加；

- 3.提升细节把控能力，如暖风芯体脏堵会导致制热不足，需定期清洁；
- 4.树立“用户需求导向”的维修理念，如除霜除雾故障需优先修复（影响行车安全）。
