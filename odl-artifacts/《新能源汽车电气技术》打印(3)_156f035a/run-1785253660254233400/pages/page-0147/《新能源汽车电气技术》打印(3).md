系统、控制开关等。 刮水器系统各部件的作用： 1.刮水器片 刮水器片：日常行驶中，刮水器片能清除风窗玻璃上的灰尘、泥土及昆虫尸体等杂物，

保持玻璃清洁，使驾驶人获得良好的视野，减少视觉疲劳。保护风窗玻璃：刮水器片在工作 时可防止雨水、灰尘等长时间附着在玻璃上形成污渍，避免其对玻璃造成腐蚀或磨损，延长 风窗玻璃的使用寿命。如图 4-18 所示。

2.刮水器臂 刮水器臂：为刮水器片提供稳固的支撑，使其能贴合在风窗玻璃表面。通过合理的设计

和结构，刮水器臂可保证刮水器片在不同的工作状态下，如不同车速、不同角度等，都能与 玻璃保持良好的接触，从而有效地刮除雨水和杂物。将刮水器电动机的动力传递给刮水器片， 带动刮水器片做往复运动。刮水器臂通常与刮水器电动机的输出轴相连，电动机的转动通过 刮水器臂转化为刮水器片在风窗玻璃上的摆动，实现对玻璃的清洁功能。可以通过调整刮水 器臂的角度，使刮水器片更好地适应风窗玻璃的曲率和不同的清洁区域，确保刮水效果。同 时，刮水器臂还能根据需要施加适当的压力在刮水器片上，使刮水器片与玻璃之间保持合适 的摩擦力，既保证刮水效果，又不会因压力过大损伤玻璃或加速刮水器片的磨损。如图 4-19
