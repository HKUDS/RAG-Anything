# 任务一 电气元件的识别和检修

##  学习目标

![](<《新能源汽车电气技术》打印(3)_images/imageFile1.png>)

知识目标

- 1.理解汽车电路的定义、基本组成及各部件功能；
- 2.掌握汽车电路图的分类及各类图纸的应用场景；
- 3.识别汽车电路图形符号的分类及核心含义；
- 4.掌握导线、插接器、开关、电路保护元件、继电器等核心元件的结构与特性；
- 5.熟悉汽车电路元件检修和线束维护的关键要点。


![](<《新能源汽车电气技术》打印(3)_images/imageFile2.png>)

能力目标

- 1.能够准确识读汽车接线图、线束图、原理框图及电气原理图；
- 2.能够在比亚迪秦 EV 实车上识别导线、插接器、开关等核心电路元件；
- 3.能够规范完成导线、插接器、继电器的基础检修操作；
- 4.能够绘制简单的汽车电路组成框架图，记录元件关键参数。


![](<《新能源汽车电气技术》打印(3)_images/imageFile3.png>)

素养目标

- 1.养成严谨细致的工作态度，重视电路检修中的安全规范；
- 2.提升团队协作与沟通能力，高效完成小组实训任务；
- 3.培养职业敬业精神，形成规范操作、文明施工的职业习惯；
- 4.具备自主查询资料、解决实际问题的创新思维。
