# 一、灯光系统组成

汽车灯光系统是车辆安全行驶的重要组成部分，主要用于照明、信号传递和警示。汽车 灯光系统从灯光所在位置分类可分为外部灯光和车内灯光。外部灯光包括前照灯、日间行车 灯、雾灯、转向灯、示宽灯（位置灯）、制动灯、倒车灯和危险警告灯（双闪）等；内部灯 光包括仪表板灯、阅读灯、氛围灯和行李舱灯等。这些灯光在车上的位置如图 3-22 所示。

1.外部灯光 外部灯光的作用主要是照明和信号表达，不同灯光的作用和特点如下：

- （1）前照灯 最主要的照明灯光，包括近光灯和远光灯。新能源汽车的前照灯一般与

转向灯、位置灯等集成在车前左右两侧，称为左前组合灯和右前组合灯。近光灯用于夜间或 穿越隧道等外部光线较暗时提供基本照明，光束较短，在会车时避免眩目对向车辆。而远光 灯光线更强，照射距离远，拓广车主观察视野，需在无对向车辆时使用。

- （2）日间行车灯 白天自动点亮，提高车辆辨识度，多为 LED 光源，能耗低。
- （3）雾灯 分为前雾灯和后雾灯。前雾灯为黄色或白色，穿透力强，用于雨雾天气。


后雾灯为红色，亮度高，提醒后车保持距离。在现代汽车设计中，许多车型都在取消雾灯配 置，以简化生产过程并降低成本。虽然前雾灯可以提高雨雾天气行车时的照明，但在实际驾 驶过程中，许多其他照明设备和功能已经可以满足类似的需求。例如比亚迪秦 PLUS 就没有 前雾灯，部分车型也只保留了一个后雾灯。
