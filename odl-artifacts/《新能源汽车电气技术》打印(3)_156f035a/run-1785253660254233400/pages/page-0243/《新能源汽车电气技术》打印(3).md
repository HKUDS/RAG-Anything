开启除霜开关时，ACU 控制鼓风机高速运转，除霜风口全开。 三、PTC 暖风系统工作原理（液体加热型）

- 1）制热起动：车主开启暖风，设定温度 25℃，ACU 检测到车内温度（如 10℃）低于

设定值，向高压配电盒发送“PTC 工作指令”。

- 2）PTC 加热：高压配电盒闭合 PTC 继电器，动力蓄电电池向 PTC 加热器供电（如 350V），

PTC 陶瓷发热体发热，将冷却液加热至 60-80℃。

- 3）冷却液循环：ACU 控制冷却液循环泵运转，将加热后的冷却液输送至暖风芯体；
- 4）暖风输出：ACU 控制鼓风机运转（根据风量需求调整转速），空气吹过暖风芯体，

吸收热量后变为暖风（出风口温度 30-40℃），通过风道送入车内。

- 5）温度调节：当车内温度接近设定温度（如 23℃）时，ACU 降低 PTC 功率（或间歇性

断电），调整循环泵转速，维持车内温度稳定。

- 6）保护机制：若 PTC 温度＞85℃（过温）或电流＞20A（过流），ACU 立即切断 PTC


高压供电，确保安全。 四、暖风系统关键参数与测量 PTC 工作参数通过诊断仪读取 PTC 相关数据流： PTC 供电电压：300-400V（与动力蓄电池电压匹配）。 PTC 工作电流：5~15A（功率 2~5kW，电流随功率变化）。 PTC 温度：正常工作温度 40~85℃（超过 85℃触发保护）。 出风口温度暖风最大制热模式下（设定温度 25℃，环境温度 5℃），出风口温度应≥

30℃。若温度＜20℃，需检查 PTC 是否工作、暖风芯体是否堵塞。

鼓风机转速通常分为 3~5 档，高速档转速约 2000r/min，低速档约 800v。通过诊断仪读 取转速数据，或直接观察出风口风量（转速低则风量小）。
