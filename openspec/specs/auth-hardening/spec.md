# Auth Hardening

## ADDED Requirements

### Requirement: Manufacturing endpoints require authentication
All manufacturing API endpoints SHALL require a valid Bearer token via `Depends(get_current_user)`.

#### Scenario: Unauthenticated request to manufacturing QA
- **WHEN** a request without an Authorization header is sent to `POST /api/manufacturing/qa`
- **THEN** the system returns HTTP 401 with detail "Token 格式无效"

#### Scenario: Authenticated request to manufacturing QA
- **WHEN** a request with a valid Bearer token is sent to `POST /api/manufacturing/qa`
- **THEN** the system processes the request normally

### Requirement: WebSocket endpoints require authentication
All WebSocket endpoints SHALL validate a `token` query parameter before accepting connections.

#### Scenario: WebSocket connection without token
- **WHEN** a WebSocket connection is attempted to `/ws` without a `token` query parameter
- **THEN** the system closes the connection with code 4001 and reason "缺少认证令牌"

#### Scenario: WebSocket connection with valid token
- **WHEN** a WebSocket connection is attempted to `/ws?token=<valid_jwt>`
- **THEN** the system accepts the connection and begins sending progress events

### Requirement: Image serving endpoint requires authentication and path validation
The `/api/knowledge/files/image` endpoint SHALL require authentication and SHALL restrict file access to the uploads directory only.

#### Scenario: Unauthenticated image request
- **WHEN** a request without an Authorization header is sent to `GET /api/knowledge/files/image?path=example.jpg`
- **THEN** the system returns HTTP 401

#### Scenario: Path traversal attempt
- **WHEN** an authenticated request attempts to access `path=../../../.env`
- **THEN** the system returns HTTP 403 with detail "不允许访问上传目录外的文件"

#### Scenario: Symlink access attempt
- **WHEN** a file path resolves to a symlink pointing outside the uploads directory
- **THEN** the system returns HTTP 403 with detail "不允许符号链接"

### Requirement: Admin endpoints enforce RBAC permissions
Settings, monitor, and workflow endpoints in the admin router SHALL use `require_permission()` dependency instead of bare `get_current_user`.

#### Scenario: Viewer role accessing admin settings
- **WHEN** a user with `viewer` role sends `GET /api/admin/settings`
- **THEN** the system returns HTTP 403 with detail "权限不足"

#### Scenario: Admin role accessing admin settings
- **WHEN** a user with `admin` role sends `GET /api/admin/settings`
- **THEN** the system returns the current settings

### Requirement: File upload filename sanitization prevents path traversal
All file upload endpoints SHALL sanitize filenames using `os.path.basename()` and validate extensions against an allowlist.

#### Scenario: Path traversal filename
- **WHEN** a file is uploaded with filename `../../../.env`
- **THEN** the system saves it as `<random>_.env` in the uploads directory (basename extraction)

#### Scenario: Disallowed file extension
- **WHEN** a file is uploaded with extension `.sh`
- **THEN** the system returns HTTP 400 with detail "不支持的文件类型: .sh"

### Requirement: JWT secret is consistent across multi-worker deployments
The JWT signing key SHALL be generated inside `init_db()` with a database transaction, not at module import time.

#### Scenario: Multi-worker startup
- **WHEN** 4 uvicorn workers start simultaneously
- **THEN** all 4 workers use the same JWT secret loaded from the settings table or generated by the first worker

#### Scenario: JWT_SECRET environment variable set
- **WHEN** the `JWT_SECRET` environment variable is set
- **THEN** the system uses that value regardless of what is stored in the database

## REMOVED Requirements

### Requirement: Unauthenticated access to manufacturing endpoints
**Reason**: Security vulnerability — exposed knowledge graph, process library, and fault case data to unauthenticated users.
**Migration**: Clients must now include a valid `Authorization: Bearer <token>` header with requests to manufacturing endpoints.

### Requirement: Unauthenticated WebSocket connections
**Reason**: Security vulnerability — leaked processing file paths and progress information to any network client.
**Migration**: WebSocket clients must pass `?token=<jwt>` as a query parameter.
