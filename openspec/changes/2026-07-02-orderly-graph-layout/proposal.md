# Orderly Knowledge Graph Layout

## Summary

将知识图谱从纯 d3-force 自由力导向布局改为**三层有序结构化布局**（同心圆 → 网格吸附力仿真 → 列式布局），让图谱在全节点数范围内看起来规整、有序、舒适。

## Problem

当前布局的根本问题——按节点数分场景：

### ≤200 节点（Tier 1 已有，需修复）

同心圆布局已实现，但碰撞仿真破坏了圆环结构——50 tick 无约束的 `forceCollide` 让节点漂离圆环位置。需改为**环约束碰撞**。

### 201-500 节点（Tier 2 待实现）★ 用户痛点

当前降级为"增强力仿真"。但力仿真的物理本质决定了它永远无法规整——更强的排斥力/碰撞半径只是让节点分布更均匀，不会产生"整齐排列"的视觉效果。用户反馈："依旧混乱"。

### 500+ 节点（Tier 3 待实现）

增强力仿真完全失控。即使用 Canvas 渲染解决了帧率问题，1000 个在屏幕上随机跳动的圆点本身就不可能是"规整"的。需要确定性布局。

## Proposed Solution

**三层布局策略，从精致到规整逐级降级：**

```
Layer 1 (≤200 节点):      Layer 2 (201-500):         Layer 3 (500+):
同心圆 + 环约束碰撞       网格吸附力仿真              列式布局
                          ┌──┬──┬──┬──┐
    ╭────────╮            │●│●│●│●│●│               Col1  Col2  Col3  Col4
   ╱  内圈    ╲           │●│●│●│●│●│               ●     ●     ●     ●
  │  ╭────╮   │           │●│●│●│●│●│               ●     ●     ●     ●
  │  │核心│   │           │●│●│●│●│●│               ●     ●     ●     ●
  │  ╰────╯   │           │●│●│●│●│●│               ●     ●     ●     ●
   ╲          ╱           └──┴──┴──┴──┘               ●     ●     ●     ●
    ╰────────╯                                        
                          力仿真收敛 → 吸附格点      按 degree 分列 → 垂直排布
```

### Tier 1: 同心圆布局（≤200 节点）— 修复

- 分位数环形分配（替代 `ratio > 0.5/0.2/0.03`）→ 每圈节点数均匀
- 环约束碰撞（替代自由碰撞仿真）→ 节点只调角度、不离开圆环
- 溢出检测：某环节点过多时降级标签，不降级布局

### Tier 2: 网格吸附力仿真（201-500 节点）— 新增

- 先跑增强力仿真让节点自然分布 → 保留拓扑关系
- 收敛后将每个节点吸附到最近网格点 → 视觉规整
- 冲突解决：两节点抢同一格点 → 低 degree 让位，BFS 找最近空余格点
- 短暂微调仿真调整边长度

### Tier 3: 列式布局（500+ 节点）— 新增

- 按 degree 降序排列节点，等分为 5-8 列
- 每列内节点均匀垂直排布
- 边用贝塞尔曲线连接，控制点偏移与列间距成正比
- 完全确定性——同一数据永远同一位置
- 默认不渲染标签，zoom>1.2 或 hover 时显示

## Impact

| 维度 | 变化 |
|------|------|
| 200-500 节点视觉规整度 | ↑↑↑ 网格对齐替代随机分布 |
| 500+ 节点视觉规整度 | ↑↑↑↑ 列式布局绝对规整 |
| 200-500 节点布局确定性 | ↑↑ 同一数据收敛结果相近 → 吸附到附近格点 |
| 500+ 节点布局确定性 | ↑↑↑ 完全确定性 |
| 代码复杂度 | ↑ 新增 ~200 行（网格吸附 + 列式布局） |
| ≤200 节点体验 | → 修复碰撞后更好（节点不漂离圆环） |

## Non-Goals

- 不改后端 API 或数据模型
- 不改 KnowledgeGraphD3 组件（制造知识图谱页）
- 不引入第三方布局库
- 不支持用户手动切换布局模式（本版）

## Rollback

- `USE_ORDERLY_LAYOUT = true` 开关（已有）
- `false` 回退到纯力仿真布局（所有 Tier）
