# Proposal: 智能制造专业智能体

## Why

第六届全国智能制造应用技术技能大赛需要一套智能化的教学辅助系统，当前缺乏将赛项知识图谱、多模态教学资源（视频/代码/工艺文档）与企业实际案例打通的专业智能体。本项目基于 RAG-Anything 多模态检索引擎，构建面向智能制造教育场景的"专业智能体"，实现从知识梳理→多模态入库→智能问答→平台部署的完整闭环。这是对 RAG-Anything 在垂直行业领域的首个端到端应用验证。

## What Changes

- **新增** 赛项知识图谱与能力标签体系：梳理大赛赛题结构，构建知识图谱，建立技能能力标签树
- **新增** 多模态知识库构建流水线：结构化赛题/评分标准/企业工艺库/故障案例库，教材知识点对齐标注
- **新增** 多模态智能体核心功能模块：文本问答、视频片段定位、资源溯源、谱系关联推送、代码解析、故障诊断问答
- **新增** 平台部署与运维方案：院校试点测试、企业场景适配、"天工讲堂"平台集成、3个月运维保障
- **新增** 行业专家论证与数据治理流程：含专家论证、数据清洗、版权审核环节

## Capabilities

### New Capabilities
<!-- Each creates specs/<name>/spec.md -->

- `manufacturing-knowledge-graph`: 赛项知识图谱构建与能力标签体系。梳理大赛各赛项的知识结构，建立技能标签树，支持谱系关联与能力画像匹配。
- `multimodal-knowledge-pipeline`: 多模态知识库构建流水线。赛题结构化、评分标准数字化、企业工艺库/故障案例库搭建、教材知识点对齐、多模态资源标注，含数据清洗与版权审核。
- `multimodal-manufacturing-agent`: 智能制造多模态智能体。文本问答、视频片段定位、资源可溯源、定制化部署、谱系关联推送、代码解析、故障诊断问答等核心推理能力。
- `platform-deployment-and-ops`: 测试优化与平台部署。院校试点测试、企业场景适配、天工讲堂平台部署、3个月运维保障、用户培训与迭代优化。

## Impact

- **新增模块**: `raganything/manufacturing/` — 智能制造领域专用模块（知识图谱、能力标签、故障诊断、代码解析）
- **新增配置**: `config/manufacturing.yaml` — 赛项配置、知识库路径、智能体行为参数
- **新增文档**: 需求规格说明书、架构设计文档、部署运维手册、用户培训材料
- **依赖系统**: RAG-Anything 核心引擎（多模态解析、向量检索、图谱构建）、天工讲堂平台 API
- **数据资产**: 第六届大赛全赛题数据集、企业工艺故障案例库、教材知识点对齐映射表
- **外部协作**: 行业专家论证、院校试点反馈、版权审核方
