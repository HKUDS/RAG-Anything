# 智能制造专业智能体 — 需求规格说明书

> **版本**: v1.0 | **状态**: 初稿 | **最后更新**: 2026-06-12

## 1. 项目概述

### 1.1 项目背景
本项目为第六届全国智能制造应用技术技能大赛构建"智能制造专业智能体"系统，作为大赛的教学辅助与技能评估工具。

### 1.2 项目目标
- 构建赛项知识图谱，梳理大赛全赛题知识结构
- 建立多模态知识库（文本/视频/代码/工艺文档）
- 开发智能问答与故障诊断智能体
- 完成天工讲堂平台部署与运维

### 1.3 核心用户
| 用户角色 | 需求场景 |
|----------|----------|
| 参赛学生 | 知识点查询、代码解析、故障模拟诊断 |
| 指导教师 | 教学资源检索、能力评估辅助 |
| 大赛评委 | 评分标准参考、选手能力画像 |
| 企业工程师 | 工艺查询、故障案例参考 |

## 3. 非功能需求

| 需求类型 | 指标 | 目标值 |
|----------|------|--------|
| 性能 | 检索响应 P95 | ≤ 2s |
| 并发 | 最大 QPS | ≥ 50 |
| 可用性 | 月度 | ≥ 99.5% |
| 准确率 | 赛题结构化 | ≥ 95% |
| 安全 | 数据隔离 | 按院校物理隔离 |

## 4. 约束与假设

- 基于 RAG-Anything 引擎，不修改核心代码
- 视频仅处理已录制内容，不支持实时流
- 需通过行业专家论证与版权审核
